References and citing
=====================

If you find DMK useful in your work, please star the repository and cite the DMK paper:

.. code-block:: bibtex

   @article{jianggreengard2025dmk,
     author  = {Jiang, Shidong and Greengard, Leslie},
     title   = {A dual-space multilevel kernel-splitting framework for discrete and
                continuous convolution},
     journal = {Communications on Pure and Applied Mathematics},
     volume  = {78},
     number  = {5},
     pages   = {1086--1143},
     year    = {2025},
     doi     = {10.1002/cpa.22240},
     url     = {https://onlinelibrary.wiley.com/doi/abs/10.1002/cpa.22240},
   }

The experimental ESP periodic solver is based on the prolate spheroidal wave function
approach described in
`Nature Communications <https://www.nature.com/articles/s41467-026-73232-8>`_.
